# 💬 PHP Chat Application

## 📖 Sobre

- `login.php` / `users.php` — autenticação e listagem de usuários
- `chat.php` — tela de conversa
- `chatapp.sql` — schema do banco MySQL
- `style.css` — estilização

## 🚀 Como rodar

1. Importe o `chatapp.sql` no seu MySQL
2. Configure a conexão no projeto
3. Sirva a pasta com PHP (ex.: XAMPP) e acesse pelo navegador

## 🛠️ Tecnologias

PHP • MySQL • CSS

## 💡 O que aprendi

- Sessões e autenticação em PHP
- Modelagem simples de banco para mensagens entre usuários
